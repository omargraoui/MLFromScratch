the repository, use the following description and topics.

derivations, tests, reproducible benchmarks, and scikit-learn validation.

**Topics**

`machine-learning`, `machine-learning-from-scratch`, `python`, `numpy`, `data-science`,
`algorithms`, `linear-regression`, `logistic-regression`, `kmeans`, `pca`, `gradient-descent`

**Suggested repository name:** `machine-learning-from-scratch`

Publication and a remote CI run are separate from building and verifying this local repository.
